## Install in Manus

Download the individual `.skill` file using GitHub’s Download raw file button. In Manus, open Skills, select Add, then Upload a skill. Upload one package per skill. The repository contains multiple skills; do not import the whole repository as a single skill.

## Other AI tools

Copy the selected skill directory into the skill directory supported by your AI tool. Inspect its SKILL.md, supporting files, dependencies, and permissions before using it. Manus-specific runtime tools may need an adapter.
